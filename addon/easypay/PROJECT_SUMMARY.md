# Easypay支付插件项目总结

## 项目概述

本项目为Niushop V5电商系统开发了一个完整的Easypay(Dulupay)支付插件，实现了支付宝、微信支付、QQ钱包等多种支付方式的集成。

## 技术栈

- **后端语言**: PHP 7.0+
- **框架**: ThinkPHP 5.x (Niushop V5)
- **数据库**: MySQL 5.6+
- **支付网关**: Dulupay/Easypay
- **签名算法**: MD5
- **测试框架**: PHPUnit
- **包管理**: Composer

## API接口

### 核心接口

1. **发起支付** - `Easypay::pay()`
2. **查询支付** - `Easypay::query()`
3. **退款处理** - `Easypay::refund()`
4. **关闭订单** - `Easypay::close()`
5. **签名验证** - `Easypay::verify()`

### 回调接口

1. **异步回调** - `/addon/easypay/notify/index`
2. **同步回调** - `/addon/easypay/return/index`
